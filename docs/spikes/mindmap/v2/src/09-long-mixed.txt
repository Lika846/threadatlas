=== t349 | Grocery spending app for my household | py-data | budgeting | en
U: I export our bank transactions as CSV every month. I'd like a small Python script that categorises grocery spending and shows the trend.
A: Start with keyword rules, which work well for repeated merchants:

```python
import pandas as pd

rules = {"groceries": ["REMA", "KIWI", "COOP", "MENY"], "transport": ["RUTER", "VY"], "eating out": ["PEPPES", "STARBUCKS"]}

def categorise(text):
    t = text.upper()
    for cat, words in rules.items():
        if any(w in t for w in words):
            return cat
    return "other"

df = pd.read_csv("transactions.csv", sep=";", decimal=",", parse_dates=["Dato"], dayfirst=True)
df["category"] = df["Beskrivelse"].map(categorise)
monthly = df[df["Beløp"] < 0].groupby([pd.Grouper(key="Dato", freq="ME"), "category"])["Beløp"].sum().unstack().abs()
monthly.plot(marker="o")
```

U: "other" is 40% of everything
A: Print the top "other" descriptions by amount and add keywords for the biggest ones: `df[df.category == "other"].groupby("Beskrivelse")["Beløp"].sum().sort_values().head(30)`. Two or three rounds usually brings "other" under 10%.
U: can it learn categories instead of me typing keywords?
A: You could train a small classifier on descriptions you've already labelled, but for a household with maybe 50 recurring merchants, a keyword list plus a CSV of manual overrides is simpler and more transparent. Learning makes sense when you have thousands of different merchants.

=== t351 | Deploying a small app cheaply | git-devops | web-backend | en
U: I built a small Node + Postgres app for my sports club. What's the cheapest reliable way to host it?
A: A few options around 0–10 euros a month:
- a small VPS (Hetzner, around 4–5 euros) running Docker Compose with Node and Postgres — cheapest, but you maintain it;
- a PaaS like Render or Railway with a managed Postgres — easier, slightly more expensive;
- Fly.io with a small Postgres volume.
For a club app with little traffic, a VPS with automatic backups is the best value if you're comfortable with Linux.
U: I'm comfortable with Linux. How do I do backups for Postgres?
A: A nightly cron job with `pg_dump`, compressed, copied off the server:

```bash
pg_dump -Fc clubdb > /backups/clubdb-$(date +%F).dump
find /backups -name '*.dump' -mtime +14 -delete
rclone copy /backups remote:club-backups
```

Test a restore into a separate database once — a backup you haven't restored isn't a backup.
U: and https?
A: Put Caddy in front of the app: it gets and renews Let's Encrypt certificates automatically with a two-line config (`club.example.com { reverse_proxy app:3000 }`). Point your domain's A record to the VPS first.
